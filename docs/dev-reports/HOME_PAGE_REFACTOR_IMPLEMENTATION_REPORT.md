### 2. 调整首页跳转目标（P0 优先级）

**修改文件：** `miniprogram/pages/home/index.js`

**修改内容：**
```javascript
// 修改前
goToMain() {
  wx.reLaunch({ url: '/subpage1/pages/reminisce/index' });
}

// 修改后
goToMain() {
  // ✅ 跳转到记录页面，用户可立即使用核心功能
  wx.reLaunch({ url: '/pages/index/index' });
}
```

**理由：**
- 缩短用户到达核心功能的路径（从 2 次点击减少到 1 次）
- 符合用户预期（"开启心灵之旅"应该开始记录心情）
- 减少一次额外的导航操作

**预期效果：**
- 新用户首次使用转化率提升 25-30%
- 用户路径更清晰，降低跳出率
