## 🔧 技术细节备忘

### 主题切换机制

```javascript
// 时段映射
const hour = new Date().getHours();
if (hour < 6) themeClass = 'bg-night';
else if (hour < 14) themeClass = 'bg-morning';
else if (hour < 18) themeClass = 'bg-afternoon';
else themeClass = 'bg-night';
```

**注意：** 当前实现中，CSS 类名已定义但渐变色统一使用默认值。如需完全实现时段主题，需要在 WXSS 中添加：

```css
.bg-morning {
  background: linear-gradient(180deg, #FFF9E6 0%, #F0F0FF 50%, #E6E6FA 100%);
}

.bg-afternoon {
  background: linear-gradient(180deg, #FFF5E6 0%, #FFE6CC 50%, #FFD6E0 100%);
}

.bg-night {
  background: linear-gradient(180deg, #E6E6FA 0%, #D8D8F0 50%, #C8C8E0 100%);
}
```

### 新用户识别逻辑

```javascript
const isFirstVisit = !userInfo.nickname || !hasRecords;
```

**说明：** 
- 如果用户没有昵称 OR 没有记录过心情，视为新用户
- 新用户会看到欢迎卡片
- 老用户会看到个性化问候

### 缓存策略

```javascript
// 心语加载失败时使用缓存
const cachedMotivation = wx.getStorageSync('cachedMotivation');
this.setData({
  motivation: cachedMotivation || '默认心语'
});
```

**建议：** 在心语成功加载后，应该缓存起来：

```javascript
// 在 getMotivation 成功后添加
wx.setStorageSync('cachedMotivation', res.data.motivationContent);
```
