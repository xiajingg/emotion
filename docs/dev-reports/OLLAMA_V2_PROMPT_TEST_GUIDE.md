# Ollama V2 Prompt 优化说明

## 📋 概述

本次优化针对情绪分析功能进行了 Prompt 升级，主要改进点：

1. **新增 `emotion` 字段** - 输出更有画面感的情绪标签
2. **优化 `suggestion` 字数** - 从 20-50 字增加到 80-150 字
3. **提升回复质量** - 更像真人对话，减少 AI 味

---

## 🎯 核心改进

### 1. 新增 emotion 字段

**V1 版本：**
```json
{
  "score": 35,
  "suggestion": "抱抱你..."
}
```

**V2 版本：**
```json
{
  "score": 35,
  "emotion": "情绪透支",
  "suggestion": "你最近的累，不像是身体没休息好..."
}
```

**情绪标签风格参考：**
- ❌ 普通词：开心、难过、沮丧
- ✅ 画面感：情绪透支、深夜低电量、轻度内耗、社交疲惫、硬撑状态、慢慢放松、情绪回暖、小小开心、被治愈的一天

---

### 2. Suggestion 字数增加

| 版本 | 字数要求 | 特点 |
|------|---------|------|
| V1 | 20-50 字 | 简洁但略显单薄 |
| V2 | 80-150 字 | 更丰富、更有共鸣感 |

---

### 3. 避免 AI 味重的表达

**❌ 不要使用：**
- "根据你的描述"
- "建议调整心态"
- "请保持积极"
- "早点休息"
- "加油"
- "不要难过"

**✅ 推荐使用：**
- "一直在硬撑"
- "假装没事"
- "偷偷消耗自己"
- "已经很久没真正放松"
- "情绪在慢慢透支"

---

## 💡 示例对比

### 示例 1：疲惫状态

**输入：**
> "今天正常上班，正常聊天，但回家后什么都不想做。"

**V1 输出：**
```json
{
  "score": 35,
  "suggestion": "抱抱你，工作中的挫折确实让人难受。记得照顾好自己，明天会更好！"
}
```

**V2 输出：**
```json
{
  "score": 35,
  "emotion": "情绪透支",
  "suggestion": "你最近的累，不像是身体没休息好，更像是一直在硬撑。白天正常工作、正常聊天，但情绪其实已经偷偷消耗很久了。你不是懒，只是真的太久没有让自己放松过了。"
}
```

**对比分析：**
- ✅ V2 新增了情绪标签 "情绪透支"，更有画面感
- ✅ V2 的建议更长（86字 vs 32字），更能引起共鸣
- ✅ V2 使用了"硬撑"、"偷偷消耗"等有情绪画面感的表达

---

### 示例 2：期待放假

**输入：**
> "明天终于放假了，好想睡到自然醒。"

**V1 输出：**
```json
{
  "score": 78,
  "suggestion": "太棒了！好好享受假期，放松身心！"
}
```

**V2 输出：**
```json
{
  "score": 78,
  "emotion": "轻松期待",
  "suggestion": "能感觉到你最近紧绷了很久，连放假都变成了一件值得开心的小事。终于可以暂时从忙碌里抽离出来，好好休息一下了，这种期待本身就很治愈。"
}
```

**对比分析：**
- ✅ V2 的情绪标签 "轻松期待" 比单纯的分数更有温度
- ✅ V2 理解了用户"紧绷很久"的背景，更有深度
- ✅ V2 的"期待本身就很治愈"更有共鸣感

## 🎯 评估标准

### 好的 V2 输出应该具备：

1. **情绪标签有画面感**
   - ✅ "情绪透支"、"深夜低电量"
   - ❌ "难过"、"开心"

2. **建议像真人对话**
   - ✅ "你最近的累，不像是身体没休息好，更像是一直在硬撑"
   - ❌ "抱抱你，明天会更好"

3. **字数符合要求**
   - ✅ 80-150 字
   - ❌ < 50 字或 > 200 字

4. **避免 AI 味**
   - ✅ 不使用"根据你的描述"、"建议调整心态"
   - ✅ 使用"一直在硬撑"、"偷偷消耗自己"

5. **保留温柔感**
   - ✅ 理解用户的疲惫，但不过度负面
   - ❌ 过于消极或冷漠
