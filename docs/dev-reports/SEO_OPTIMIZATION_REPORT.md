# 情绪解压卡 SEO 优化说明

## 项目定位

当前项目是微信小程序，核心能力是让用户输入烦恼或情绪文本，生成单次完整的情绪解压卡，包括情绪分析、压力解压建议、高情商回复、情绪周报和心情回顾。

因此本次 SEO 优化重点不是传统网页的 `meta keywords`，而是微信小程序搜索更容易读取和展示的内容：

- 小程序项目描述
- 页面导航标题
- `sitemap.json` 收录规则
- 首屏核心文案
- 分享给朋友和朋友圈的标题

## 已完成优化

### 1. 强化小程序整体定位

修改文件：

- `miniprogram/app.json`
- `miniprogram/project.config.json`

优化内容：

- 将默认导航标题统一为“情绪解压卡”
- 将项目描述调整为“输入烦恼，生成情绪分析、解压建议和高情商回复，帮你快速整理压力、焦虑和内耗困扰。”

优化原因：

原有标题更像泛品牌名，对搜索用户来说意图不够明确。新命名“情绪解压卡”更贴近问题导向，同时简介覆盖核心搜索词：`情绪`、`解压`、`压力缓解`、`焦虑缓解`、`内耗`、`高情商回复`。

- `miniprogram/subpage1/pages/reminisce/index.json`

优化原因：

页面标题是小程序搜索和分享场景中的高权重信号。调整后，每个页面都围绕一个明确搜索意图：

- 主页面承接“情绪分析 / 压力缓解 / 回复生成”
- 周报页承接“情绪周报 / 情绪趋势”

### 3. 按官方规则优化 sitemap 收录质量

修改文件：

- `miniprogram/sitemap.json`

优化内容：

- 增加 sitemap 说明
- 改为白名单收录策略
- 仅允许以下公开入口页被微信索引：
  - `pages/index/index`
  - `subpage1/pages/answer-book/index`
- 使用 `{"action": "disallow", "page": "*"}` 排除其他页面

优化原因：

微信小程序官方 sitemap 机制用于配置页面是否允许被微信索引；如果没有 sitemap，默认所有页面都允许被索引。官方规则中 `{"action": "allow", "page": "*"}` 是最低优先级默认规则，未显式禁止的页面会默认允许索引。

因此，对这个项目更合理的做法不是继续 `allow *`，而是采用白名单：只开放不依赖用户私密数据、进入后能展示明确功能主题的页面。情绪周报、心情回顾、答案历史、好友共享、福利页等页面要么依赖登录后的个人数据，要么搜索意图较弱，不适合作为公开搜索入口。

### 4. 优化主页面首屏语义

修改文件：

- `miniprogram/pages/index/index.wxml`
- `miniprogram/pages/index/index.js`

优化内容：

- 将输入卡片标题调整为“把烦恼整理成一张卡”
- 将按钮文案调整为“生成情绪诊断与减压回复”
- 将下滑提示调整为“AI 情绪分析、缓解建议与回复话术”
- 增加“压力焦虑”场景标签
- 调整输入占位文案，加入压力、焦虑、睡不好、情绪崩溃、高情商回复等真实搜索词

优化原因：

主页面是核心落地页。原文案偏“嘴替”和情绪记录，对“压力大怎么办”“焦虑怎么缓解”“AI情绪分析”“高情商回复”等搜索意图覆盖不足。新文案在不改变核心交互的前提下，把产品能力表达得更清楚。

### 5. 优化分享标题

修改文件：

- `miniprogram/pages/index/index.js`
- `miniprogram/pages/weekly-report/weekly-report.js`
- `miniprogram/subpage1/pages/reminisce/index.js`
- `miniprogram/subpage1/pages/answer-book/index.js`

优化内容：

- 主页面分享标题突出“AI情绪分析与压力缓解”
- 周报分享标题突出“情绪解压卡周报”和“压力趋势”

优化原因：

微信小程序的传播链路依赖转发和朋友圈标题。标题中直接表达问题和收益，可以提升点击率，也能让微信搜索和社交推荐更容易理解页面主题。

## 后续建议

1. 在微信公众平台补充小程序服务类目、简介和搜索关键词，保持与本次代码中的关键词一致。
2. 为分享卡片补充稳定的 `imageUrl`，让社交分享结果更可控。
3. 如果后续做 H5 落地页，再补充传统 SEO：`title`、`description`、结构化数据、Open Graph、站点地图等。
