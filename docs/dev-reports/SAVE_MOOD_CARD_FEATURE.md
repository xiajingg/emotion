# 保存心情卡片功能说明

## 📋 功能概述

将"存入心迹"按钮改为"保存心情卡片"，点击后会将用户的情绪分析结果生成一张精美的PNG图片并保存到手机相册。

## ✨ 主要改进

### 1. 按钮文案更新
- **修改前**：存入心迹
- **修改后**：保存心情卡片

### 2. 图片设计优化

#### 视觉元素
- 💖 **标题区域**：显示"心情卡片"和当前日期
- 💬 **用户问题**：用引号包裹，斜体显示，突出情感表达
- 🎯 **情绪分数徽章**：圆形设计，金色分数数字，醒目展示
- 🏷️ **情绪标签**：根据分数显示对应的情绪状态（如"愉悦·充满活力"）
- 💡 **情感建议**：AI生成的个性化建议
- 🎨 **背景装饰**：渐变背景 + 半透明圆形装饰

#### 配色方案
- **背景渐变**：紫色 (#667eea) → 深紫 (#764ba2) → 粉色 (#f093fb)
- **文字颜色**：白色为主，金色用于分数
- **透明度**：使用 rgba 实现层次感

### 3. 技术实现

#### 文件修改
1. **index.js**
   - `saveToDiary()` → `saveMoodCard()`
   - 优化 `drawShareContent()` 方法，重新设计卡片布局
   - 调整画布尺寸为 750x1334（更适合手机屏幕）
   - 优化渐变背景为三色过渡

2. **index.wxml**
   - 按钮绑定事件：`bindtap="saveToDiary"` → `bindtap="saveMoodCard"`
   - 按钮文本：`存入心迹` → `保存心情卡片`

#### 核心流程
```
用户点击"保存心情卡片"
    ↓
调用 saveMoodCard()
    ↓
调用 generateAndSaveImage()
    ↓
创建 Canvas (750x1334)
    ↓
绘制渐变背景
    ↓
绘制卡片内容（标题、问题、分数、建议等）
    ↓
转换为临时图片文件
    ↓
调用 wx.saveImageToPhotosAlbum()
    ↓
保存到手机相册
    ↓
显示成功提示
```

## 📝 注意事项

### 1. 权限处理
- 首次保存会请求相册权限
- 用户拒绝后会引导去设置页面
- 需要用户在系统设置中手动开启权限

### 2. 图片质量
- Canvas 使用设备像素比（dpr）渲染
- 确保在不同设备上清晰度一致
- 图片尺寸为 750x1334 逻辑像素

### 3. 性能优化
- 图片生成过程显示 loading
- 避免频繁调用（防重复点击已在其他按钮实现）
- Canvas 节点复用，不每次创建

### 4. 用户体验
- 成功提示持续2秒，足够用户看到
- 失败时有明确的错误提示
- 授权引导友好，不会让用户困惑
